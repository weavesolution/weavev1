| `og-cover.jpg` | 1200×630 | Link preview card for WhatsApp and Google |

**Screenshots:** take them on a clean window at full screen, with realistic
sample data — real-looking names and amounts, no "Test 123" rows. Blur or replace
any actual client name before uploading.

**Compress everything** to under 300 KB (squoosh.app) so the site stays fast on mobile.
